Frontend Documentation
======================

Frontend Overview
-----------------
This file highlights frontend architecture and how it integrates with both backends.
Routing is handled in App.jsx, and major features live in /components.

Chatbot UI Flow
---------------
Chatbot.jsx renders the policy advisor UI and streams chat responses.
It calls /api/rag-chat or the configured chat API base.
Messages are rendered in a two-column layout with voice control.

Claim UI Flow
-------------
ClaimChecker.jsx collects claim files and metadata.
ClaimStoryChatbot.jsx and ClaimResult.jsx render narratives and decisions.
