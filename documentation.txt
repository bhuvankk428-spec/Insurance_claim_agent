Project File Documentation
==========================

Note: This file documents all tracked project files outside of .git and node_modules.

Root
-----
- .env: Shared environment configuration for frontend and both backends.
- .gitignore: Git ignore rules for generated and local-only files.
- eslint.config.js: ESLint configuration for code quality.
- index.html: Vite HTML entry template.
- package-lock.json: NPM lockfile for root dependencies.
- package.json: Root scripts and dependencies (frontend + tooling + backend runner).
- postcss.config.js: PostCSS configuration for Tailwind.
- README.md: Project overview, setup instructions, and environment info.
- tailwind.config.js: Tailwind CSS configuration.
- vite.config.js: Vite build/dev configuration.
- documentation.txt: This documentation file.

Backend - Chat (RAG)
-------------------
- backend\chat\.env: Local chat backend env file (root .env is source of truth).
- backend\chat\db.js: PostgreSQL connection pool for RAG retrieval.
- backend\chat\package-lock.json: NPM lockfile for chat backend.
- backend\chat\package.json: Chat backend dependencies and scripts.
- backend\chat\policy_chunks.json: Prebuilt policy chunks used for RAG indexing.
- backend\chat\rag.js: RAG pipeline and streaming response logic (Ollama).
- backend\chat\retrieval.js: Embedding + vector similarity retrieval logic.
- backend\chat\rules.js: Rule-based scoring layer for policy ranking.
- backend\chat\server.js: Chat backend HTTP server (RAG API).

- backend\chat\data\agri.json: Agriculture policy source data.

Backend - Chat Scripts
---------------------
- backend\chat\scripts\buildChunks.js: Builds chunked policy documents for RAG.
- backend\chat\scripts\embedChunks.js: Embeds chunks into pgvector for retrieval.

Backend - Claimcheck
-------------------
- backend\claimcheck\.env: Local claimcheck env file (root .env is source of truth).
- backend\claimcheck\eng.traineddata: Tesseract OCR language data.
- backend\claimcheck\package-lock.json: NPM lockfile for claimcheck backend.
- backend\claimcheck\package.json: Claimcheck backend dependencies and scripts.
- backend\claimcheck\server.js: Claimcheck HTTP server and middleware setup.
- backend\claimcheck\config\domains.js: Domain configuration for claim types.
- backend\claimcheck\routes\claim.routes.js: API routes for claim workflow + admin endpoints.
- backend\claimcheck\services\evidence.service.js: FIR + image evidence validation.
- backend\claimcheck\services\exif.service.js: Image EXIF extraction for geo check.
- backend\claimcheck\services\extractFields.service.js: Field extraction from OCR text.
- backend\claimcheck\services\match.service.js: Matching logic for policy/FIR/evidence.
- backend\claimcheck\services\ocr.service.js: OCR pipeline for PDFs/images.
- backend\claimcheck\services\policy.service.js: Policy verification + claim creation.
- backend\claimcheck\services\story.service.js: Story analysis + decision logic + Supabase write.
- backend\claimcheck\services\supabase.service.js: Supabase client + claim persistence.
- backend\claimcheck\store\claimStore.js: In-memory claim store for workflow state.
